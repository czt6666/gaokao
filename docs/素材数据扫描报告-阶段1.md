## 三、与现有数据库的对应关系

| 素材内容 | 目标数据库表 | 当前缺失情况 |
|----------|-------------|-------------|
| 院校投档线/专业分数线 | `admission_records` | 部分省份不全（江苏、广东等） |
| 一分一段表 | `rank_tables` | 部分省份缺少2024数据 |
| 批次线 | `province_control_lines` | 部分省份不全 |
| 院校基础信息（含保研率） | `schools` | 部分字段缺失（如保研率） |
| 专业就业信息 | `major_employment` | 部分专业缺失 |
| 院校就业报告 | `school_employment` | 只有部分学校有数据 |
| 院校满意度 | `major_satisfaction` | 部分数据缺失 |
| 就业避坑指南（1000所院校流向） | `school_employment_flow` | 数据量较少 |
| 招生计划 | `majors` | 部分省份2025数据不全 |
