# 水卢冷门高报引擎 · 项目总览

> 一句话定位：不是"查分数对应学校"的工具，而是用**概率模型 + 机器学习 + 真实口碑**帮你发现"同样分数能去更好学校"的决策引擎。

---

## 一、产品架构

```
前端（Next.js + 微信小程序）
    ↓ HTTP / 云函数
后端（FastAPI + SQLite）
    ├── /api/recommend      核心推荐（冲/稳/保 + 冷门挖掘）
    ├── /api/agent/chat     AI 志愿助手（联网搜索 + 意图识别）
    ├── /api/payment        微信支付
    └── /api/auth           微信登录 + 手机登录
    ↓
数据层（SQLite：gaokao-local.db）
    ├── 录取数据：247 万条 admission_records（8 年 × 31 省 × 3000+ 校）
    ├── 学校画像：档次、城市、学科评估、就业、口碑
    ├── 用户数据：注册、订单、行为事件
    └── 一分一段表：45,032 条（分数 ↔ 位次换算）
```

---

## 二、核心功能

| 功能 | 说明 |
|------|------|
| **冲稳保推荐** | 输入省份+位次+选科，返回 96 所分层推荐（冲 25 + 稳 46 + 保 25） |
| **冷门宝藏** | 从冲稳区挖掘"被市场低估但价值高"的学校（城市冷/名字冷/学科强/满意度高） |
| **AI 志愿助手** | 独立页面 `/ai-chat`，支持联网搜索实时数据、意图识别直跳推荐 |
| **选科匹配** | 支持 3+1+2、3+3、旧高考三种模式，SQL 层硬过滤不可报专业 |
| **专业限制** | 过滤色盲/色弱/性别/外语等身体条件限制 |
| **PDF 报告** | 付费解锁完整 9 模块深度分析（概率→就业→学科→城市→策略） |
| **分销裂变** | 邀请付费用户得 7 天会员，无上限叠加 |

## 四、产品边界（红线）

| 红线 | 说明 |
|------|------|
| 不给本科考生推荐专科/高职 | 除非考生位次在后 50%（`_is_low_rank` 阈值） |
| 报告数量 ≥ 30 所 | 正常数据省份，低于 30 自动补"参考"标注 |
| 支付前后数据必须不同 | 未付费仅展示 1 所完整数据 + 其余模糊化 |
| 禁止 alert() / confirm() | 全用 in-page toast（2500ms） |
| 禁止硬编码域名/IP | 必须用环境变量 `SITE_URL` |

## 六、与竞品的差异

| 维度 | 传统工具（夸克/优志愿） | 水卢 |
|---|---|---|
| 核心逻辑 | 分数匹配（排队） | 价值发现（套利） |
| 概率精度 | "大概能录" | "63% [55%–71%]，小年窗口" |
| 数据来源 | 官方录取线 | 官方线 + 真实口碑 + 招聘数据 |
| 推荐深度 | 列表 | 500 字深度分析 + 策略建议 |
| 算法透明度 | 黑箱 | 白箱（每步数学过程可解释） |
| 定价 | ¥0 或 ¥360/年 | ¥39 单次 / ¥99 季卡 |
