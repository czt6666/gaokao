## 3. Explode 导入（核心）

把每行多年 xlsx「炸开」成 `admission_records`（一年一行），同时写 `admission_2026`（2026 计划）。

```bash
cd backend

# 3a. Dry-run 扫描：统计每省行数 / 科类 / 批次分布，不写库
.venv/bin/python -m importers.explode_importer \
  --dir "/Users/czt/workspace/webfrontend/高考程序素材/2026"

# 3b.（可选）只查 batch_type 覆盖率
.venv/bin/python -m importers.explode_importer \
  --dir "/Users/czt/workspace/webfrontend/高考程序素材/2026" --check-batches

# 3c. 正式导入：清空两表 → 重新写入（含 ensure_schema 自动补新列）
.venv/bin/python -m importers.explode_importer \
  --dir "/Users/czt/workspace/webfrontend/高考程序素材/2026" --apply
```

`--apply` 会 `DELETE FROM admission_records / admission_2026` 后重灌，并重置 sqlite_sequence。

### 涉及的映射逻辑

- **列识别**：`importers/column_mapper.py` 的 `ColumnMap.detect()`（表头在第 2/3 行，列数 56~84 不等）
- **静态映射表**：`importers/static_maps.py`
  - `BATCH_TYPE_MAP` — 批次文本 → 标准 `batch_type`
  - `SUBJECT_MUST_MAP` / `SUBJECT_ANY_OF_MAP` — 选科要求 → 结构化
  - `PLAN_CATEGORY_MAP` — 计划类别 → `major_restrictions`（国家专项/地方专项/定向/公费师范/中外合作等）
  - `get_is_985_211` / `get_derived_category` — 院校标签、科类
- **关键坑**：3+1+2 省份「不限选科」记录会丢首选科目，导入时按 `category`（科类列）补回 `subject_must`（物理/历史）。

## 4. 回填派生字段

导入后跑两个回填脚本，补全推荐系统依赖的科类血统与首选科目。

```bash

# 4a. derived_category：用 (min_score,min_rank) 对一分一段做最近匹配，
#     把 '不限'/再选科目 还原成 物理类/历史类/综合

.venv/bin/python scripts/backfill_subject_must_category.py --verify
```

## 5. 一分一段表（rank_tables）

## 7. 部署上线

> 代码与数据是**两个独立通道**：`theyuanxi_deploy.sh` 只 rsync 代码（显式 `--exclude='*.db'`，不碰库）；
> 数据用 `migrate_2026_to_prod.sh` 全量替换两表。
> **推荐顺序：先数据、后代码**——新代码要读 `major_full` 等新列，先上代码会因旧 schema 缺列报错。

### 7a. 数据同步（替换线上两表）

```bash
cd backend
bash migrate_2026_to_prod.sh           # 演练：导出精简库(~190MB gz)+上传+打印线上行数，不写库
bash migrate_2026_to_prod.sh --apply   # 正式：备份→ATTACH→事务内 DELETE+INSERT 替换→重启 backend
```

- 导出脚本 `scripts/export_admission_tables.py` 只含 `admission_records` + `admission_2026`。
- apply 会自动 `ALTER` 补新列、备份到 `db-backup/gaokao.db.bak-<时间戳>`。
- **回滚**：脚本结尾会打印
  `ssh <SERVER> 'cp db-backup/gaokao.db.bak-<TS> gaokao.db && sudo systemctl restart gaokao-backend'`
- ⚠ `rank_tables` 不在同步范围；如线上缺 2026 一分一段，稳区会回退 ±15%。需单独确认/同步。

### 7b. 代码部署

```bash
cd /Users/czt/workspace/webfrontend/gaokao
bash theyuanxi_deploy.sh   # rsync 前后端代码 → 服务器 pnpm build → 重启 backend+frontend
```
