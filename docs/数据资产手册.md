# 数据资产手册

> 本文档记录系统依赖的全部数据表、数据量、以及两个数据库的差异。

## 一、数据库现状（重要）

| 数据库 | 文件大小 | 有效数据 | 状态 |
|--------|---------|---------|------|
| `gaokao.db`（服务器版） | 579 MB | **≈ 0 行**（仅 7 条 user_events） | ❌ **空壳，推荐算法无法运行** |
| `gaokao-local.db`（本地版） | 917 MB | **267 万行** | ✅ **当前主库** |

**原因**：服务器版数据已被清空或迁移（文件保留历史分配但未 VACUUM），所有业务表均为空。生产环境疑似已切到云端数据库或其他存储。

## 二、核心数据表（25 张）

### 录取与分数（3 张）

| 表名 | 本地版行数 | 说明 |
|------|-----------|------|
| `admission_records` | **2,472,737** | 历年专业录取记录（省×校×专业×年），**算法核心输入** |
| `rank_tables` | 45,032 | 一分一段表（分数 ↔ 位次） |
| `province_control_lines` | 5,691 | 各省批次控制线 |

### 院校与专业（4 张）

| 表名 | 本地版行数 | 说明 |
|------|-----------|------|
| `schools` | 3,402 | 学校基础信息（档次、城市、性质、排名） |
| `majors` | 21,434 | 专业招生信息（含选科要求、计划数、学费） |
| `national_programs` | 53,671 | 全国院校开设专业目录 |
| `subject_evaluations` | 68,021 | 教育部第四轮学科评估（A+/A/A-/B+…） |

### 就业与口碑（11 张）

| 表名 | 说明 |
|------|------|
| `major_employment` | 专业级就业数据（薪资、就业率、满意度） |
| `school_employment` | 学校级就业数据（多源验证后的可靠版本） |
| `school_reviews` | 学生口碑（贴吧/知乎等舆情分析） |
| `school_employment_flow` | 毕业生就业流向明细 |
| `school_salary_ranking` | 院校薪资排名 |
| `school_order_programs` | 订单班/校企合作专业 |
| `industry_salary_benchmark` | 行业岗位薪资基准 |
| `industry_summary` | 行业薪资汇总 |
| `major_employment_dist` | 专业就业分布明细 |
| `major_industry_map` | 专业关键词到行业映射 |
| `major_satisfaction` | 专业满意度评分 |

### 用户与商业化（7 张）

| 表名 | 说明 |
|------|------|
| `users` | 注册用户（微信/手机登录） |
| `orders` | 付费订单 |
| `user_events` | 行为埋点（页面访问、按钮点击） |
| `feedbacks` | 用户意见反馈 |
| `sms_codes` | 短信验证码（替代内存存储） |
| `report_logs` | PDF 报告生成记录 |
| `report_scans` | 报告二维码扫描记录 |

## 三、数据来源与更新

| 数据类型 | 来源 | 更新频率 |
|----------|------|---------|
| 录取数据 | 各省教育考试院公开数据 | 每年 6–8 月批量导入 |
| 学科评估 | 教育部第四轮学科评估 | 静态（第五轮未公开） |
| 就业数据 | 教育部就业质量报告 + 上市公司招聘数据 + 社区口碑 | 季度更新 |
| 一分一段表 | 各省考试院 | 每年高考后 |
| 控制线 | 各省考试院 | 每年高考后 |
