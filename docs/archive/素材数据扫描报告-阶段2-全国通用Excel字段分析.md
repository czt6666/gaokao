## 二、核心文件详细字段分析

### 2.1 院校信息类（补充schools表）

#### 文件1：02-全国院校基础信息-带保研率.xlsx
- **行数预估**：3238行（全国高校完整列表）
- **核心字段**：
  - 学校名称、是否985、是否211、双一流、是否强基
  - 保研率（★关键冷门判断指标：保研率越高，学校学术实力越强，但可能被忽视）
  - 硕士点数量、博士点数量（★冷门判断：硕博点多的非985/211学校）
  - 建校时间、男女比例、招生电话、邮箱、地址、官网
  - 学科评估JSON（完整第四轮学科评估结果）
  - 学校简介（可用于关键词提取特色）
- **数据库映射**：`schools` 表几乎所有字段都可补充
- **冷门挖掘价值**：**极高** — 保研率、硕博点数是判断"被低估学校"的核心指标

#### 文件3：0 3000所高校院校列表.xlsx
- **核心字段**：排名、学校名称、建校时间、学校类型、学校层次、主管部门、所在地、省份、所在城市、特色专业
- **冷门挖掘价值**：**高** — 主管部门（如工信部、国家民委）往往对应行业特色强校

#### 文件4：院校基本信息-版本1.xlsx

#### 文件17：全国高等院校信息汇总.xlsx ⭐最完整

- **核心字段**：学校id、学校名称、logo、985、211、双一流、学校类型、学科门类、所在省份、所在城市、建校时间、性质、电话、博士点、硕士点、重点学科、院士数量、男女比例、地址、邮箱、学校简介、综合排名

### 2.2 就业流向类（补充school_employment + school_employment_flow）

#### 文件2：《就业避坑指南——1000所院校就业流向》.xlsx ⭐独特数据
- **行数预估**：1000所院校
- **核心字段**：
  - 省份、城市、学校名称
  - 就业签约单位性质分布（央企/国企/民企/外企等百分比）
  - 就业签约单位行业分布
  - 主要签约单位列表（如：中国航空工业集团34人、中国电子科技集团27人...）
  - 主要签约单位说明（如：前22个重点单位共录用毕业生243人，占签约总数15.99%）
- **数据库映射**：需新建 `school_employment_flow` 表或扩展现有表
- **冷门挖掘价值**：**极高** — 这是判断"行业特色强校"的核心依据：
  - 如果某非985/211学校有大量毕业生进入特定央企/国企，说明该校在该行业有极强认可度
  - 例如：某双非院校每年30+人进中国航空工业集团 → 航空类冷门强校
  - 可构建"行业就业集中度"指标：就业越集中，行业特色越强

### 3.2 可挖掘的冷门判断新依据

基于以上数据分析，除现有算法外，还可增加以下**冷门强校/强专业判断指标**：

1. **保研率偏差指标**：保研率高的非双一流学校（行业特色研究院所）
2. **硕博点密度指标**：硕士点+博士点数量 / 学校知名度，比值越高越冷门但越强
3. **行业就业集中度**：某校毕业生进入特定央企/国企的比例（文件2）
4. **国家级特色专业标记**：文件16中的"国家级特色专业"标记
5. **专业满意度-分数偏差**：满意度高但录取分数低的专业
6. **专业薪资排名**：文件14中的"专业薪资排名"，可用于发现高薪冷门专业
7. **代表性高校列表**：文件11中各专业对应的"代表性高校"，非知名学校即为冷门强校
8. **院士数量指标**：院士数 > 0 的非双一流学校（如某些省属重点大学）
9. **主管部门指标**：工信部、国家民委、交通运输部等部委直属的非知名高校
10. **学科评估A类密度**：拥有A类学科的非双一流学校（如南京工业大学、解放军信息工程大学等）
