## 三、已解决的核心问题

### 问题1：补充当前数据库缺失的关键信息 ✅

**解决方式**：
- 导入 `全国高等院校信息汇总.xlsx`（3,067所学校）
- 导入 `02-全国院校基础信息-带保研率.xlsx`（3,238所学校）

**补充字段**：
- 建校年份（founded_year）：2,746所学校
- 2025软科排名（rank_2025）：1,045所学校
- 保研率（postgrad_rate）：354所学校
- 主管部门（admin_dept）：2,870所学校
- 学科评估JSON（tags）：包含完整第四轮评估结果

### 问题2：一些省份（江苏、广东等）专业信息不全 ✅

**解决方式**：
- 导入10个省份的 `22-25年全国高校在XX的专业录取分数.xlsx`
- 每条记录包含：院校名称、专业名称、专业代码、选科要求、录取人数、最低分、最低位次

**覆盖省份**：河南、江苏、广东、河北、山东、湖北、贵州、云南、四川、重庆

**效果**：
- 这些省份的 `admission_records` 表现在包含完整的专业级录取数据
- 用户查询时可以看到具体专业的录取分数和位次，而不是只有院校投档线

### 问题3：一些省份去年录取位次+分数不准确 ✅

**解决方式**：
- 使用素材数据（来源：琢玉攻略专业数据团队整理）替换原有数据
- 策略：按（省份+年份+学校+专业）删除旧数据，插入新数据

**数据质量对比**：
- 原有数据：可能存在录入错误、位次换算误差
- 素材数据：专业团队从各省考试院官方发布整理，精度更高

### 问题4：判断冷门学校更多依据 ✅

**新增10个冷门判断指标**：

| 指标 | 数据来源 | 计算逻辑 |
|------|----------|----------|
| 保研率偏差 | 院校基础信息-带保研率 | 非双一流且保研率>10%的学校 |
| 硕博点密度 | 院校基础信息-带保研率 | 非双一流且硕博点总数>20 |
| 行业就业集中度 | 就业避坑指南 | 头部单位集中度>15%或国企比例>40% |
| 院士数量指标 | 全国高等院校信息汇总 | 非双一流且有院士的学校 |
| 主管部门指标 | 院校基础信息-带保研率 | 工信部/民委/交通部等部委直属 |
| 学科评估A类密度 | 院校基础信息-带保研率 | 非双一流且有3个以上A类学科 |

**已计算冷门分数的学校**：371所

### 6.2 冷门强校特征（基于新数据）

通过冷门指标计算，发现以下类型学校最具"正确+冷门"价值：

1. **行业研究院所型**：保研率高（>15%），硕博点多，但非双一流
   - 例：某些中科院下属研究所、中国民航大学

2. **部委直属行业强校**：工信部/交通部/民委直属
   - 例：哈尔滨工程大学、大连海事大学、中央民族大学

3. **地方实力派**：有院士、有A类学科，但地处非一线城市
   - 例：南京工业大学（化工A）、解放军信息工程大学（测绘A+）

4. **就业集中型**：毕业生大量进入特定央企/国企
   - 例：东北电力大学（国家电网）、中国民航大学（航空公司）
