# 专业限制标签使用说明

## 一、为什么要加这列

历年录取数据里，每个专业的"专业备注"都写着各种限制条件，比如：
- 只招男生 / 只招女生
- 不招色盲 / 不招色弱
- 只招英语考生
- 国家专项计划
- 中外合作办学
- 实验班 / 基地班

**以前**：备注是自由文本，系统看不懂，推荐时会把"不招色盲"的专业推给色盲考生。

**现在**：新增 `major_restrictions` 列，把限制条件结构化，系统就能自动过滤掉不适合考生的专业。

---

## 二、这列存了什么

`major_restrictions` 存的是一串**逗号分隔的标签**，例如：

| 原始专业备注 | major_restrictions |
|-------------|-------------------|
| （只招男生） | `gender:male_only` |
| （不招色盲） | `health:color_blind` |
| （只招英语语种的考生） | `lang:english_only` |
| （国家专项） | `special:national_special` |
| （只招男生；不招色盲） | `gender:male_only,health:color_blind` |
| 无任何限制 | `''`（空字符串） |

### 目前支持的标签

| 大类 | 标签值 | 含义 | 触发场景 |
|------|--------|------|----------|
| **性别** | `gender:male_only` | 只招男生 | 考生性别为女时，过滤 |
| | `gender:female_only` | 只招女生 | 考生性别为男时，过滤 |
| **体检** | `health:color_blind` | 不招色盲 | 考生色盲时，过滤 |
| | `health:color_weak` | 不招色弱 | 考生色弱时，过滤 |
| | `health:monochrome` | 不招单色识别不全 | 考生单色识别不全时，过滤 |
| **外语** | `lang:english_only` | 只招英语考生 | 考生高考外语非英语时，过滤 |
| | `lang:english_japanese` | 只招英语/日语考生 | 考生外语非英语/日语时，过滤 |
| | `lang:english_russian` | 只招英语/俄语考生 | 考生外语非英语/俄语时，过滤 |
| **特殊类型** | `special:experiment` | 实验班/基地班/拔尖班 | 可加分推荐或单独标注 |
| | `special:national_special` | 国家专项计划 | 考生未通过资格审查时，过滤 |
| | `special:local_special` | 地方专项计划 | 考生未通过资格审查时，过滤 |
| | `special:oriented` | 定向培养 | 考生不愿定向时，过滤 |
| | `special:free_teacher` | 公费师范/师范类 | 考生不愿履约任教时，提醒 |
| | `special:sino_foreign` | 中外合作办学 | 考生不愿出国或学费不足时，提醒 |

| 国家专项 | 25,883 | 专项计划，资格审查过滤 |
| 定向培养 | 21,975 | 定向就业，意愿过滤 |
| 只招男生 | 20,194 | 性别限制，必须过滤 |

## 三、怎么用这列

### 场景1：志愿推荐时自动过滤（后端）

考生在小程序填完基本信息后，后端推荐算法读取 `major_restrictions`，把不符合条件的专业剔除：

```
考生画像：
  - 性别：女
  - 体检：色盲
  - 高考外语：日语

推荐算法逻辑：
  1. 筛掉 gender:male_only 的专业（只招男生）
  2. 筛掉 health:color_blind 的专业（不招色盲）
  3. 筛掉 lang:english_only 的专业（只招英语考生）
  4. 保留其余专业进入推荐池
```

### 场景2：前端展示提醒（小程序）

即使某个专业没有被过滤掉，也可以在前端给考生醒目的提醒：

| 专业名称 | 录取分数 | 限制提醒 |
|----------|---------|----------|
| 临床医学 | 620分 | 不招色盲 |
| 英语 | 585分 | 只招英语考生 |
| 计算机（中外合作） | 560分 | 中外合作办学 |
| 物理学（实验班） | 640分 | 实验班 |

### 场景3：考生自助筛查

在"我的条件"页面，考生可勾选自己的特殊情况：
- 我是男生/女生
- 我是色盲/色弱
- 我高考外语是日语
- 我不考虑中外合作办学
- 我不考虑定向培养

系统根据勾选条件，一键过滤掉所有不符合的专业。

## 四、对现有系统的影响

| 模块 | 影响 | 改造点 |
|------|------|--------|
| 数据库 | 新增一列 | `admission_records` 表加 `major_restrictions` |
| 数据导入 | 新增提取逻辑 | 导入Excel时，自动从"专业备注"提取标签写入该列 |
| 推荐算法 | 新增过滤逻辑 | 推荐前，根据考生条件过滤 `major_restrictions` 不匹配的专业 |
| 前端展示 | 新增提醒UI | 结果列表中展示每个专业的限制标签 |
| 用户画像 | 新增字段 | 用户表需记录性别、体检情况、高考外语语种 |

## 五、下一步需要产品决策

1. **考生画像采集**：是否在填志愿前增加一步"身体条件"采集（性别、是否色盲/色弱、高考外语语种）？
2. **过滤严格度**：是"硬过滤"（直接不显示）还是"软提醒"（显示但标红）？
   - 性别/体检/外语建议硬过滤（报了也录不了）
   - 中外合作/定向/师范建议软提醒（考生可以选，但需要知情）
3. **专项计划资格**：国家专项/地方专项需要考生提前通过资格审查，是否要在系统里做资格校验？
